Como o AdotaPet foi planejado?

O sistema completo é desenvolvido em Java 17, Spring Boot e PostgreSQL. Esta página estática é uma vitrine demonstrativa gratuita e não substitui as funcionalidades do backend.

1. Cadastro e cuidado

ONGs organizam informações dos abrigos, animais e vacinação.

2. Adoção consciente

O sistema completo prevê solicitações, análise e formalização responsável.

3. Acompanhamento

Visitas, registros e relatórios ajudam a manter a rastreabilidade.
